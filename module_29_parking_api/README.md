# 🚗 Parking API — REST API сервиса парковок

REST API на Flask для управления клиентами, парковочными зонами и парковочными сессиями.

Проект реализует бизнес-логику заезда и выезда автомобиля, контроль свободных мест, проверку состояния парковки и наличие платёжной карты у клиента при выезде.

---

## 🚀 Возможности

- ✅ Регистрация клиентов
- ✅ Хранение автомобиля и платёжной карты клиента
- ✅ Создание парковочных зон
- ✅ Контроль общего и доступного количества мест
- ✅ Проверка открыта ли парковка
- ✅ Регистрация заезда автомобиля
- ✅ Фиксация времени въезда и выезда
- ✅ Защита от повторного активного заезда
- ✅ Проверка наличия банковской карты при выезде
- ✅ Автоматическое изменение количества свободных мест
- ✅ JSON API
- ✅ Интеграционные тесты на pytest
- ✅ Factory Boy + Faker для генерации тестовых данных

## 📡 API

| Метод | Endpoint | Назначение |
|---|---|---|
| `GET` | `/clients` | Получить список клиентов |
| `GET` | `/clients/<id>` | Получить клиента по ID |
| `POST` | `/clients` | Создать клиента |
| `POST` | `/parkings` | Создать парковочную зону |
| `POST` | `/client_parkings` | Зарегистрировать заезд |
| `DELETE` | `/client_parkings` | Зарегистрировать выезд |

---

## 👤 Создание клиента

### POST `/clients`

Пример запроса:

```json
{
  "name": "Иван",
  "surname": "Петров",
  "credit_card": "1234-5678-9012-3456",
  "car_number": "А123БВ77"
}
```

Обязательные поля:

- `name`
- `surname`

Дополнительно могут быть указаны:

- `credit_card`
- `car_number`

---

## 🅿️ Создание парковки

### POST `/parkings`

```json
{
  "address": "ул. Ленина, 10",
  "opened": true,
  "count_places": 50,
  "count_available_places": 50
}
```

Сервис хранит:

- адрес парковки;
- открыта ли парковка;
- общее количество мест;
- количество доступных мест.

---

## 🚘 Заезд на парковку

### POST `/client_parkings`

```json
{
  "client_id": 1,
  "parking_id": 1
}
```

Перед созданием парковочной сессии сервис проверяет:

1. существует ли клиент;
2. существует ли парковка;
3. открыта ли парковка;
4. есть ли свободные места;
5. нет ли уже активной парковочной сессии.

После успешного заезда:

- создаётся запись `ClientParking`;
- фиксируется время въезда;
- количество свободных мест уменьшается на 1.

---

## 🚪 Выезд с парковки

### DELETE `/client_parkings`

```json
{
  "client_id": 1,
  "parking_id": 1
}
```

При выезде сервис:

1. ищет активную парковочную сессию;
2. проверяет наличие платёжной карты у клиента;
3. фиксирует время выезда;
4. увеличивает количество свободных мест.

Если банковская карта не привязана, сервис возвращает ошибку.

---

## 💾 Модели

### Client

Хранит:

- ID;
- имя;
- фамилию;
- номер банковской карты;
- номер автомобиля.

### Parking

Хранит:

- ID;
- адрес;
- состояние парковки;
- количество мест;
- количество свободных мест.

### ClientParking

Связывает клиента и парковку и хранит:

- время въезда;
- время выезда;
- `client_id`;
- `parking_id`.

## 🧪 Тестирование

Проект покрыт интеграционными тестами на `pytest`.

Проверяются:

- получение клиентов;
- создание клиента;
- создание парковки;
- заезд;
- уменьшение количества свободных мест;
- выезд;
- восстановление свободного места;
- фиксация времени выезда;
- запрет выезда без банковской карты;
- создание тестовых объектов через Factory Boy.

Для тестов используется изолированная SQLite-база в памяти.

### Запуск

```bash
pytest -v
```
