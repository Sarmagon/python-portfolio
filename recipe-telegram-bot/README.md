# 🍳 Recipe Bot — Telegram-бот для поиска рецептов

[![Python 3.10+](https://img.shields.io/badge/Python-3.10+-blue.svg)](https://www.python.org/)

Telegram-бот для поиска рецептов по названию блюда или ингредиентам через **TheMealDB API**.

Итоговый проект курса **«Основы Python»**.

Бот поддерживает русский и английский ввод, хранит историю поисковых запросов пользователей и предоставляет быстрый доступ к найденным рецептам.

---

## 🚀 Возможности

- ✅ Поиск рецептов по названию блюда
- ✅ Поиск рецептов по ингредиенту
- ✅ Поддержка русского и английского ввода
- ✅ Перевод русских названий блюд и ингредиентов для поиска через API
- ✅ FSM для управления состояниями пользователя
- ✅ История поисковых запросов
- ✅ Хранение пользователей и истории в SQLite
- ✅ Peewee ORM
- ✅ Inline- и Reply-клавиатуры
- ✅ Интеграция с внешним REST API
- ✅ Обработка сетевых ошибок API

## 🧩 Как работает бот

```text
Пользователь
    │
    ▼
Telegram Bot API
    │
    ▼
Handlers
    │
    ├── поиск по названию
    ├── поиск по ингредиенту
    ├── история запросов
    └── callback-обработчики
    │
    ├──────────────► TheMealDB API
    │
    └──────────────► SQLite + Peewee
```

FSM используется для управления этапами диалога при поиске рецептов.

---

## 🔎 Поиск по названию

Пользователь вводит название блюда на русском или английском языке.

Пример:

```text
Пицца
```

или:

```text
Pizza
```

Бот отправляет запрос в TheMealDB API и возвращает найденный рецепт:

- название блюда;
- список ингредиентов;
- инструкцию по приготовлению;
- ссылку на полный рецепт.

---

## 🥕 Поиск по ингредиенту

Пользователь может искать блюда по ингредиенту.

Пример:

```text
Курица
```

или:

```text
Chicken
```

Бот получает список подходящих рецептов и показывает пользователю до 10 результатов.

---

## 🌍 Поддержка русского языка

TheMealDB работает преимущественно с английскими названиями.

Для русского ввода в проекте используются словари переводов:

```text
русский запрос
      │
      ▼
словарь переводов
      │
      ▼
английский термин
      │
      ▼
TheMealDB API
```

Если пользователь вводит английское название, запрос сразу отправляется в API без перевода.

## 💾 База данных

Для хранения данных используется SQLite + Peewee ORM.

### User

Хранит информацию о пользователях Telegram:

- Telegram ID;
- username;
- имя;
- фамилию;
- дату регистрации.

### SearchHistory

Хранит историю поиска:

- пользователя;
- поисковый запрос;
- краткое описание результата;
- дату и время запроса.

---

## 🧠 FSM

Для управления состояниями пользователя используется встроенная FSM библиотеки `pyTelegramBotAPI`.

Реализованы состояния:

```text
waiting_for_dish_name
waiting_for_ingredient
```

Это позволяет разделить сценарии поиска по названию блюда и по ингредиенту.

## ⚙️ Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Sarmagon/python-portfolio.git
cd python-portfolio/recipe-telegram-bot
```

### 2. Создать виртуальное окружение

Windows:

```bash

venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

## 🔐 Настройка Telegram Bot Token

В проекте есть шаблон:

```text
.env.template
```

Создайте рядом файл `.env`:

```env
BOT_TOKEN=your_telegram_bot_token_here
```

Токен Telegram-бота можно получить через [@BotFather](https://t.me/BotFather).

Не добавляйте `.env` с реальным токеном в Git.
